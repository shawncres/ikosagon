The Infinite End is a highly performant procedural space-flight sim that runs in the browser on Quest 3 VR, desktop and mobile. We at Ikosagon are building it as a place to fly: gates between systems, planets you can descend to, and a radio playing as you go.

## The radio
The soundtrack is a custom AI-generated radio. We make original songs with AI and organise them into stations, so there is always something playing that exists only in this game.

## Status
Early alpha. Things change from one build to the next and some of it is rough. The LIVE DEMO link on this card opens the current test build.

## What to expect
- A galaxy generated from seeds, so every system is a place nobody has flown before
- A custom AI-generated radio of original soundtrack stations, made for the game
- Self-improving ML pathing, in development: an AI pilot that learns from recorded flights
- Flight, boost and a hyperlight drive for the long hauls between worlds
- Multi-device support from one page, with no install: Quest 3 VR, desktop and mobile browser
- Built to run smoothly, including on a headset

## Problem
Homeschool parents need learning support that fits real life: short conversations with kids, lessons that follow interest, and standards that still get covered without building a complex dashboard first.

## What this product is
An AI inquiry agent talks with children to learn strengths and interests. Overnight batches adapt a curriculum that evolves with the child while embedding real-world standards into lessons. Access starts as simple as a phone call, with a website path for visual learning. Each child has a profile. Parents use the same channels for progress and insights.

## Principles
- Accessibility first: voice on a regular phone, web when useful
- Interest-led lessons that still map to standards
- Parent visibility without a second product to learn
- Built with xAI as the model provider

## Status
Product and positioning are in progress. This portfolio site is the public home for the brand while the product is built.

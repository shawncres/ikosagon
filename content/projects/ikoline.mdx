IkoLine is how we at Ikosagon showcase **call-flow mastery** as a product — not a free-chat bot.

Years of contact-center instinct live in the graph: stages, must-say lines, escalation gates, payment-plan rules, quiet-hour awareness, and clean exits. The language model classifies intents, fills slots, and may lightly paraphrase **inside the current node**. It does not own the journey.

## For employers

- **Authored flows** as the artifact: versioned JSON skins for customer service, collections, and sales on one shared runtime.
- **NLP-in-node**: keyword-first matching (works offline); optional Groq paraphrase only when a node allows it — compliance nodes stay verbatim.
- **RAG** over a **substantial** policy/script corpus per vertical (returns, shipping, billing, hardship, quiet hours, ethical sales, and more); citations surface when the node asks for them.
- **Mock CRM tools**: lookup account, balance, payment plan, case, callback, disposition — deterministic demo accounts (`1001`, `2044`, `3300`).
- **Measured cases forthcoming**: an expanded black-box set lives in `content/ikoline/qa-cases.md` (full runner still in progress).

## For clients

A controllable agent that can run **CS / collections / sales** workflows you approve — disclosures that cannot drift, escalation when the graph says so, and answers grounded in your procedures. We shape the experience with you; the model stays on a leash.

## Honesty

- **Text-first** interactive demo on this page. No live inbound phone number (PSTN costs money; Hobby stays free).
- **Voice** (push-to-talk STT / agent TTS) is **phase 2** — UI stubs only.
- Free-tier caps apply when a model key is present; without a key the demo still advances on scripted lines + keyword intents.
- Status is **in progress**: the shared skeleton ships with a much richer corpus and conversational soft-scripts; telephony certification is not claimed.

## How to try it

1. Pick a vertical skin.
2. Walk the call in the transcript; watch the **node label** and **slot chips** update.
3. Ask policy questions (returns, hardship, plan fit) to see RAG citations.
4. Tools fire as the graph allows. Restart anytime — turn cap is 20 per session.

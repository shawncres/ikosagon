IkoLine is how we at Ikosagon showcase **call-flow mastery** as a product — not a free-chat bot.

Years of contact-center instinct live in the graph: stages, must-say lines, escalation gates, payment-plan rules, quiet-hour awareness, and clean exits. When a model key is present, Groq runs **real NLP turns** inside each node (intent + slots + natural reply). The graph still owns transitions and must-say compliance lines. Keyword matching is the offline fallback.

## For employers

- **Authored flows** as the artifact: versioned JSON skins for customer service, collections, and sales on one shared runtime.
- **NLP-in-node**: Groq classifies intents, fills slots, and speaks naturally for the current/next node; compliance nodes (`allowParaphrase: false`) lead with the must-say line verbatim. Keyword fallback when offline.
- **RAG** over a **substantial** policy/script corpus per vertical (returns, shipping, billing, hardship, quiet hours, ethical sales, and more); citations surface when the node asks for them.
- **Mock CRM tools**: lookup account, balance, payment plan, case, callback, disposition — deterministic demo accounts (`1001`, `2044`, `3300`).
- **Measured cases forthcoming**: an expanded black-box set lives in `content/ikoline/qa-cases.md` (full runner still in progress).

## For clients

A controllable agent that can run **CS / collections / sales** workflows you approve — disclosures that cannot drift, escalation when the graph says so, and answers grounded in your procedures. We shape the experience with you; the model stays on a leash.

## Honesty

- **Text-first** interactive demo on this page. No live inbound phone number (PSTN costs money; Hobby stays free).
- **Browser TTS** (Web Speech API `speechSynthesis`) optionally reads agent replies aloud — free system voices, mute toggle in the demo chrome. This is **not** production contact-center voice (no Twilio/ElevenLabs). Push-to-talk STT remains phase 2.
- Conversational turns use Groq (`CHAT_MODEL` / `openai/gpt-oss-20b`) when `GROQ_API_KEY` is set; without a key the demo still advances on scripted lines + keyword intents. Rate-limited to protect Hobby quotas.
- Status is **in progress**: shared skeleton + rich corpus + live LLM turns in-node; telephony certification is not claimed.

## How to try it

1. Pick a vertical skin.
2. Walk the call in the transcript; watch the **node label** and **slot chips** update. Leave **Agent voice** on to hear browser TTS, or mute it anytime.
3. Ask policy questions (returns, hardship, plan fit) to see RAG citations.
4. Tools fire as the graph allows. Restart anytime — turn cap is 20 per session.

# Hexcast

Hexcast is an Ikosagon featured project (2026, in progress): self-improving **ranked probability aggregation** for probability/prediction markets and sports, built on Ikosagon’s **proprietary ranking system**.

## Plain-language description

Many sources emit probabilities (models, books, markets, experts). Hexcast ranks how useful those sources have been relative to outcomes, then aggregates their forecasts into a clearer combined view. The ranking is meant to improve as new results arrive — that is the “self-improving” part. The ranking method itself is proprietary; public notes describe the idea, not the algorithm details.

# FAQ

## Can I talk to a model on this site?

Yes. The site assistant retrieves passages from markdown in content/knowledge and content/projects, then asks a cloud model (Groq, xAI, or Gemini if a key is set) to answer only from those passages. If no API key is configured, it returns the retrieved passages without generating new prose. In plain words: the assistant should only say what the notes support, and a wrong or unsourced answer counts as a bug.

## Do you host a model on Vercel?

No. Vercel Hobby has no GPU and a 250 MB function bundle. Weights do not fit. Inference runs at the provider or, separately, in the visitor browser if we add an on-device demo later. Separate client work may include edge devices as a service (for example Orin-class) or on-prem stacks — that is not what hosts this public site.

## What is IkoArtist?

IkoArtist (formerly AI Recording Artist) is a web product for almost anonymous song participation. Answer as many questions as you want to discover tastes and songs you might like — enough signal for the agentic Ikosagon engine to understand what you’d want to hear. The engine produces the hit over time; tracks compete on a view-ranked leaderboard playlist. Intake, leans, and anonymous finish are on the page. Generation runs in the pipeline, not as a live spend — no auto Suno / ElevenLabs / Gemini spend on the page. No account required. Email optional (opportunities only). /projects/ikoartist, /contact, or shawn@ikosagon.com.

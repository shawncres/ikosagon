# FAQ

## Can I talk to a model on this site?

Yes. The site assistant retrieves passages from markdown in content/knowledge and content/projects, then asks a cloud model (Groq, xAI, or Gemini if a key is set) to answer only from those passages. If no API key is configured, it returns the retrieved passages without generating new prose.

## Do you host a model on Vercel?

No. Vercel Hobby has no GPU and a 250 MB function bundle. Weights do not fit. Inference runs at the provider or, separately, in the visitor browser if we add an on-device demo later.

## What businesses do you help?

GTA and remote SMBs that leak time on intake, quotes, policy questions, and follow-up. Education product work lives under Ikosagon Learn.

## How much does a project cost?

There is no public rate card. Scope first, then a written estimate. The assistant must not invent a price.

## How do I start?

Open /contact. Include business type, the painful workflow, and a rough timeline.

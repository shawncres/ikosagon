# FAQ

## Can I talk to a model on this site?

Yes. The site assistant retrieves passages from markdown in content/knowledge and content/projects, then asks a cloud model (Groq, xAI, or Gemini if a key is set) to answer only from those passages. If no API key is configured, it returns the retrieved passages without generating new prose.

## Do you host a model on Vercel?

No. Vercel Hobby has no GPU and a 250 MB function bundle. Weights do not fit. Inference runs at the provider or, separately, in the visitor browser if we add an on-device demo later. Separate client work may include edge devices (for example NVIDIA Orin) or on-prem stacks — that is not what hosts this public site.

## What is IkoArtist?

IkoArtist (formerly AI Recording Artist) is a web product for almost anonymous song participation. Answer as many questions as you want to discover tastes and songs you might like — enough signal for the agentic Ikosagon engine to understand what you’d want to hear. The engine produces the hit over time (curated choices + adapting processes); tracks compete on a view-ranked leaderboard playlist. No account required — finish anonymously and your path still feeds the pipeline via /api/talent-intake; email is optional (opportunities only). No live auto Suno spend on the page or public price list — /projects/ikoartist, /contact, or shawn@ikosagon.com.

# Services

Ikosagon designs and ships software that upgrades existing processes for a post-AGI operating environment.

## Offers

- Product engineering and MVP builds
- Frontend systems and UI that stay readable on a phone
- AI integrations: grounded chat, intake bots, overnight batch jobs, voice or web access
- Automation around quotes, FAQs, booking, and messy documents

## Engagement shape

Short paid discovery when the problem is fuzzy. Fixed-scope prototypes when the workflow is obvious. Contract or freelance when you need someone to own the first production version.

## Constraints we respect

- Keys stay on the server. Visitors never receive provider secrets.
- Answers about Ikosagon must come from site notes, not guessed clients.
- Canadian SMBs should assume data handling is discussed up front (what is stored, where it lives, how to turn it off).
- Vercel Hobby is the current public host. It can proxy a model API. It cannot run a local 3B+ model.
